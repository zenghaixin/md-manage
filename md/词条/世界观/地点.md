# 地点

::: term [六面世界]
由人界、魔界、龙界、天界等构成的封闭宇宙。term[人神]与龙神的斗争在此循环，term[拉普拉斯战役]亦写在这套世界的年表上。
:::

::: term [布埃纳村]
term[菲托亚领]边陲的农村，term[鲁迪乌斯]转生落地之处。term[保罗]在此任卫兵，term[希露菲]也在村中长大。
:::

::: term [菲托亚领]
term[阿斯拉王国]北部边领，term[格雷拉特家]伯雷亚斯一脉的领地。term[菲托亚转移事件]后领内人口锐减，成为搜索队与重建的起点。
:::

::: term [罗亚]
term[菲托亚领]的主城。term[艾莉丝]在此作为领主家女儿长大，term[基列奴]也曾作为家中剑术教师常驻。
:::

::: term [阿斯拉王国]
中央大陆最强人类国家，贵族盘根错节。term[格雷拉特家]是其剑术贵族的一支，term[亚莉艾尔]的王位争夺亦在此展开。
:::

::: term [拉诺亚魔法大学]
北方拉诺亚王国的最高魔法学府。term[鲁迪乌斯]、term[洛琪希]、term[赞恩]、term[希露菲]都曾在此求学或任教。
:::

::: term [米里斯神圣国]
信仰圣神的宗教国家，term[杰尼斯]的故乡。迷宫与神殿并存，term[米里斯迷宫攻略]即发生于此。
:::

::: term [魔大陆]
人类难以定居的严酷大陆，魔族与魔兽横行。term[贝加利特旅行]的起点，term[洛琪希]的故乡term[米格路迪亚族]村落也在其中。
:::

::: term [红龙山脉]
分隔term[魔大陆]与人界的巨型山脉，红龙盘踞。死亡行军穿越此地，是term[贝加利特旅行]中最危险的路段之一。
:::

::: term [希龙王国]
以人偶术与工匠闻名的国家，term[赞恩]的母国。政治上接近term[阿斯拉王国]的卫星。
:::

::: term [剑之圣域]
term[剑神流]的根据地，由term[剑神加尔]镇守。想要剑王以上的名号，几乎都必须来此挑战。
:::
