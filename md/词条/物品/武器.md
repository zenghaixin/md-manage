# 武器

::: term [魔力铠]
term[赞恩]与term[鲁迪乌斯]合作打造的魔力驱动外骨骼。以庞大魔力换取接近列强级的身体能力，是鲁迪后期近战的核心装备。
:::

::: term [龙神剑]
term[奥尔斯特德]持有的神器级兵刃，能与龙神的身体能力相匹配。寻常圣剑在其面前难以完整交锋。
:::

::: term [恶魔之眼]
term[岸里卡]借出的魔眼。term[鲁迪乌斯]先后使用过预见、鉴定等不同类型，用于预判杀招与看穿迷宫结构。
:::

::: term [超族三叉戟]
term[卢德格尔]的爱枪，超族传统兵器。枪身坚固、适合贯穿铠甲，在term[贝加利特旅行]中多次成为前排的决定性武器。
:::

::: term [始源魔导具]
古代魔文明留下的触媒与武装残件。term[佩尔吉乌斯]的空中要塞中收藏甚多，部分可放大term[无咏唱魔法]的规模。
:::
